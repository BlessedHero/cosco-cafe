# COSCO Cafe

Premium online-first Seoul cafe landing page for `cosco.kr`.

**Coffee. Soda. Cookies.**  
Sip, fizz, bite.

## Project

This is a static HTML/CSS landing page mockup for COSCO Cafe. It includes a
product-forward hero, menu trio, cafe box builder, Seoul delivery messaging, and
domain deployment notes.

## Files

- `index.html` - landing page markup
- `styles.css` - responsive styling and brand system
- `assets/cosco-hero.png` - generated product hero image
- `DEPLOY_COSCO_KR.md` - Vercel and Gabia DNS setup notes
- `vercel.json` - simple Vercel static-site config

## Run Locally

Open `index.html` directly in a browser.

## Deploy

This site can deploy as a static project on GitHub Pages or Vercel. A `CNAME`
file is included for the `cosco.kr` GitHub Pages custom domain.

For Vercel setup, see `DEPLOY_COSCO_KR.md`.
